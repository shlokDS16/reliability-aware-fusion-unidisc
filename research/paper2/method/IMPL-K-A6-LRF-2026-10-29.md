## What each piece does

1. **Fold builder.** Universe = captioned val2017 images with an instance annotation (and a file in `val2017.zip`). Excluded: folds cal/head/test/test_ext, probes 1 and 2, M1 and M5 item files (required unless `--allow-missing-optional`), the FOIL pool, all 1,560 SugarCrepe images (SHA-256 verified), the family-H file if present. c+ is drawn
   uniformly among captions with 5 to 32 tokens; a seeded permutation of the eligible images gives idx 0-519, gid 8000+idx. Primary negative: `folds.assign_negatives` unchanged. Length-matched negative: exact token count among category-disjoint other items, else the smallest |difference| (ties uniform).
   Leak check L0-L7 plus the L8 self-test (injected leak with every source, repeated image, gid collision, wrong negative); nothing is written if either fails. Deterministic (tested, also independent of dict order).
2. **`--neg-len`.** One extra `Lambda` pass per item (`full_image_lp`), `{cond}_deltaL` stored for every condition (denoised and token-level too), row `imgL` (none and gate0.05 summaries). Needs item field `neg_caption_len` (caption text); otherwise ValueError. Tested: +1 pass, nothing else moves.
3. **`--extra-cells`.** `<type><severity>` cells appended after the sanity conditions (so no earlier condition index or jitter stream moves) as pixel conditions through `suite.apply_corruption`, seed `suite.corruption_seed(gid, 1000 + 10*type_index + severity)`; no text-direction passes for them.
   Tests: all existing cells byte-identical with and without extras; an extra cell and the same pixel image through the ordinary family path (same condition index) give equal arrays (12 keys incl. B, D, s3, tex, nbr, tbv, three flag sets).
4. **`--caption-slot-len N` (coordinator addendum).** B, D, s3, tbv (and the flags and top-k arms) are scored on `sc.build([PAD]*N, codes)`; D comes from the existing `DI_n0NN` cache; Lambda and Delta are unchanged. Tests: a slot equal to the true length reproduces every array;
   a different slot moves B, D, tbv only; another caption of the same image gives identical fixed-slot scores (content irrelevant, caption masked). `--gate-true-layout` keeps flags and size-matched arms at the true layout (+8 passes per gated condition).
5. **Re-score stage `run_gate_lrf_rescore`.** Reads the source run (default `P2-GATE-M4`) read-only; copies codes, z, delta, tex, nbr; re-scores B, s3, D, tbv at the fixed slot (36 passes per item, no encode, no Lambda); re-derives GATE-M flags with the source run's condition index (so the jitter stream is the source's);
   stores only the keys `analysis_posthoc.learned_ceiling.data.load` reads. Invariance check (c+ and c- in the slot, cut or padded to L_FIX, against PAD) on the first 5 items, written to the row (`invariance_max_abs_diff`, must be 0). Tested: slot = true length reproduces the source arrays exactly, including flags.
   Cost estimate: 36 passes x 500 items, no encoding (the M4 item is 75 passes).
6. **Scorer.** Refuses (HashMismatch) on any difference of model.npz, any file of spec `code_sha256` (raw or LF-normalised), the feature list, and any key of an optional `--pins` JSON (model_sha256, code_sha256, scoring_code_sha256, decision_rule). Features by the frozen `data.engineer` loaded by path; numpy GAM. Decision `sum w*Delta > 0`, ties and all-zero weights wrong.
   Recomputes Y_NONE and Y_GATE-M and asserts equality with the runner row. Verified against the real frozen model and `lrf.infer_item` (see claims).
7. **Analysis.** L1/L2 one-sided exact, L3/L4 two-sided Holm (m = 2), fixed sequence, L-NI (90% bootstrap bound vs -0.03), L-LEN (mismatched items excluded and counted), LG (Holm over the preregistered m = 3, absent cell as p = 1, first 300 items, n < 240 descriptive), length-stratum secondary,
   labels per A6.12 (partial prefix below 416). Seeds `SeedSequence(20261028, spawn_key=(34,))` into 13 fixed slots; output byte-identical on rerun; `--selftest` (size, sequence logic, NI bound).
