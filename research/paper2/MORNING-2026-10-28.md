## Significance and validation (your bar: "something really significant with proper validation through results and figures")

### 1. Is GATE significant beyond the closest work? Honest answer: not yet proven
- **What is new** (novelty re-audit, confidence 0.50, narrow delta still open): on a pretrained unified multimodal masked-diffusion
  model with no fine-tuning, each INPUT token is scored against the rest of its own modality with the other modality withheld.
  A conformal-risk-control threshold, calibrated on clean pairs, decides which tokens to flag. We then measure whether
  re-masking or re-infilling them preserves two-way image-text verification under corruption.
- **What is not new** (must not be claimed): detect-and-remask itself (Trust but Verify 2610.22380, text only, needs fine-tuning,
  hand-set threshold); cross-modal remasking in a unified MDM (CO2Jump 2607.13188, which remasks its own outputs); conformal
  risk control for caption errors (Gomes et al. 2504.01225); and qualitative repair of corrupted pairs (UniDisc appendix G.1).
- **Risks to significance** (red team): the 21-item dry run suggests the model score is weak on JPEG and noise, where a pixel
  check does better; there is one small model (UniDisc 1.4B); and the Information Fusion fit has to be argued.
- **What would make it significant** (recommended, in order of value per GPU-hour):
  a. **Include patch and swap corruptions in the main test** (where the theory predicts the largest gain), disclosed as decided
     after the dry run. This is cheap, because M4 already encodes a patch image per item.
  b. **Re-infill results with real repaired images** (SHOULD S2) with the UniDisc G.1 recipe as a matched baseline. This is the
     visual evidence a reviewer looks for. About 1 GPU-h (estimate) on top of MUST.
  c. **A second model** (Omni-Diffusion 8B, 4-bit; COULD E7) to answer "one small model". It is untested on this GPU, the 4-bit
     path on Blackwell is unverified, and it cannot be costed until a 20-pass timing run exists. About a day of risk.
  d. **A published corruption benchmark** (for example foil captions) instead of only injected corruptions. Not yet scoped;
     needs a data check and a statistician addendum.

### 2. Validation plan (preregistered; card v3)
- **Experiments:** M1 token-level detection (finish probe 2); M2 calibration on 300 clean pairs; M3 blind headroom check on 100
  items; M4 main test on 300 items (500 if the sample-size rule says so); M5 coherence test. SHOULD: S1 caption typos,
  S2 re-infill, S3 hard negatives, S4 denoise+GATE, S5 ablations.
- **Primary test:** GATE vs no gate on corrupted pairs, exact McNemar, Holm over 3 corruptions; a claim counts only if GATE wins.
- **Baselines and controls:** no gate; geometry-matched and scattered random gates; oracle gate; changed-code gate;
  TbV-score (non-finetuned); max-probability; pixel-variance and neighbour-distance (non-generative); pixel denoiser; UniDisc
  G.1 (in S2).
- **Metrics:** matching accuracy; token-level AUROC (item-clustered bootstrap); realised false-alarm proportion on clean items
  against alpha; per-item evidence ratio d.
- **Real-output figures:** per-token reliability heat-maps on the 32x32 grid; corrupted / flagged / repaired image strips;
  ROC curves against all baselines; realised false-alarm vs alpha; matching accuracy by arm and corruption with CIs. Probe 1
  F1/F2 already exist.
- **If the result is null:** reported as null; the card fixes what counts as negative.
