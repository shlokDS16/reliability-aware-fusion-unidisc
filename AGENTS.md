# DLM Discovery

Research project: find, test and publish one new result on diffusion language models or unified
multimodal discrete-diffusion models, for an A* venue.

## Every session
1. `graph-memory brief`, then the RESUME block of `research/progress.md`. Nothing else up front.
2. Operating rules: `research/FRAMEWORK.md` (sections 5 to 7 for delegation, ledgers and gates).
   The long-form reference is `DLM_Research_Discovery_Blueprint.md`; read sections on demand.
3. Subagents live in `.Codex/agents/` and are generated by `python tools/build_agents.py`.
   Every brief points to `research/CONTRACT.md`. At most 3 agents at once.
4. Facts go into ledgers with `python tools/ledger.py add <ledger> --file row.json`. Rows are
   append-only.
5. End of session: update `research/progress.md`, then
   `graph-memory sync --note "<what changed>" --next "<next step>"`, then the routine in
   `Codex/routines.md`.

## Hard rules
- Planned is not done; predicted is not observed; an Exa or README summary is E1, not a reading.
- No number in any document unless it is in a `runs/<exp-id>/` directory.
- Proposer is never validator. Gates pass only on a `gate-auditor` verdict.
- Hardware is a 12 GB laptop GPU. Downloads above 5 GB and any cloud spend need the user's yes.
- Prose is edited for clarity with `research-humanizer`; the venue's LLM-use statement stays in.
- Excluded topics: conformal water-quality retrieval (GLORIA); evaluation protocol and battery
  state of health.

## Engineering standards (apply once code exists)
