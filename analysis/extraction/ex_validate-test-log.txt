SPEC AMBIGUITIES RESOLVED (choice in each case; 24)
 A1  Fixture lines. Fixture line ranges count lines split at "\n" only. M03416.txt holds 4 lone CR characters;
     Python universal newlines would shift l.845-887 by 4 and lose the Table 3 caption. The CLI reads the text
     the same way (bytes split at "\n", trailing CR removed).
 A2  N2 forms. Three token forms are tried in order: raw (no join), line-end hyphen kept, hyphen dropped. The
     page joins only at line ends; a quoted label or header joins any token ending in letter/digit + "-" with the
     next token (so "Qwen3-30B- A3B-Inst-2507" matches either way). The first form with a match decides.
 A3  N3 arrows. Arrows are split off and dropped from row tokens as well as header tokens (both sides of every
     comparison get the same treatment; a glued "0.15↑" would otherwise make the next token mid-line and the row
     incomplete).
 A4  N5. One leading "(" and one trailing ")" are stripped independently, so "(Score | TPF)" gives Score, TPF.
 A5  N6. Only the integer-only line nearest the page end among the last three non-blank lines is dropped (one
     footer per page, so a row ending in integer cells keeps them); it also applies to the last page, which has
     no following marker (V35 needs this).
 A6  map_not_in_header is token membership (every token of every leaf part occurs among the header tokens), not a
     contiguous run: in M13864 the leaf "Time (sec.)" is split by "BLEU COMET" in the header and V28 expects pass.
 A7  Two-level order. Bottom-level parts and level-1 parts (consecutive repeats collapsed) must both align
     greedily in header order; a one-part leaf counts at both levels. Failure is the warning
     column_order_unverified (V06, V28 unverified; V11, V14, V22 verified, as expected).
 A8  Ungrouped rows in a grouped table. A cell with row_group '' is accepted when its row lies between the header
     and the first row-group line (M08100 "Average", the worked-example F1 cell H04); otherwise
     row_group_missing (V16 still fails).
 A9  Row search region. Without row groups the row is searched from the line after the header when the header is
     on the cell's page, else from the page start (v0.2 searched the whole page; prose above a table could make a
     row ambiguous). A separate check header_near_row requires the header on the cell's page or the page before
     (v0.2 check 5); the table-entry header check uses table.page or table.page - 1 (v0.3).
 A10 Continuation entries (first_col > 1). The token offset of earlier elements is taken from the same row's other
     entries; elements no entry covers count one token each (V27 has no first_col 1 entry).
 A11 Row width with declared blanks. The count is still compared with the leaf map; a mismatch fails. v0.3 names
     only rows without blanks; a blank is declared only to fill the row to the map, so a different count is an
     error either way.
 A12 Check 10 benchmark and metric. Checked only when a part of columns[col] has that role (column_roles; a
     one-part leaf takes level 1's role). The unit's string must equal the joined parts of that role or one of
     them, by the s5.4 key, or by label-core (one trailing parenthesis) so "Time" matches "Time (sec.)". In
     columns orientation the row label has no declared role, so the benchmark is not checked against it.
 A13 Check 10 condition (K units). Compared as a multiset of " / " parts with the same leniency. Expected parts:
     header parts with role condition; the row group when row_group_role is condition; in columns orientation the
     row label unless it equals the unit's benchmark or metric (U9).
 A14 second_factor_mismatch (K units only). When row_group_role or the level-1 column role is second-factor, an
     empty second_factor_printed is a mismatch.
 A15 rowgroup_benchmark_mismatch also applies to H units (they carry benchmark_printed; 'not stated' skipped) and is
     skipped when the cell's row_group is '' (row_group_missing already reports it).
 A16 Comparisons. Arm labels and second factors: strict U11 key (normalise, trailing citation with a year,
     "(ours)" and markers removed, lower case, no whitespace); no label-core. column_mismatch: normalise with all
     whitespace removed, case and arrows kept.
 A17 where_mismatch. v0.2 check 8 (H unit loc.where against the table) is kept, and the same check is applied to a
     K group's where against the table of every cell its values cite.
 A18 Captions. A caption not starting with Table, Tab., Figure or Fig. is reported as caption_start (fail); v0.2
     names only caption_not_found and caption_length. No negation window is applied (v0.2 check 6).
 A19 Sign, group rule. v0.5 "units of one group with the same metric key and different values" is read as two K
     units of one group whose metric key (lookup id, else raw: + s5.4 key) is equal and whose higher_is_better
     differs, null counting as a value (KA1: "Units of one group with the same metric_printed get one value").
 A20 Sign, arrow rule. Rejection (arrow_conflict) for an arrow in column_printed against higher_is_better (v0.5
     s10.3) and, in a columns-oriented group, an arrow in the cited cell's row label (KA1(a) "row label"). It is
     applied to H units too (KA1 covers H units). null with a printed arrow is the warning
     direction_null_with_arrow. Arrows printed next to the leaf in the table header (red-team v0.5 mn2) give only
     a warning plus EC route, because arrow attribution in a linearised header is not certain (M12766 prints
     "Overall ↑Objects").
 A21 EC routing (K units). Route when the metric is unmapped or its lookup direction is null (sign_extractor_only)
     or the extractor value differs from the lookup, null against a lookup value included (sign_lookup_conflict).
     Default lookup = the KA1(b) list built in (plan v0.5 s5.4); --metric-lookup reads a CSV printed,id,
     higher_is_better (the columns of analysis/extraction/fixtures/lookups/metric-ids-v1.csv, which another
     session created while this ran). KA1(b) qualifiers stripped before lookup: top-1, avg., gen., average, mean.
 A22 figure-only and unreadable. A K value "figure-only" is exempt only in a unit with figure_only true (V31/V32);
     an H value "figure-only" only with origin F1-figure; "unreadable" needs a cell entry (rows checked, value not).
 A23 New statuses where v0.2/v0.3 name none: occurrence_mismatch (occurrence beyond the matches), row_group_unknown,
     header_not_near_row, table_missing, evidence_missing, col_missing, unreadable_needs_cell; value_occurrence
